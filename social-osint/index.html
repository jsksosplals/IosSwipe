Social OSINT

Рабочее место для проверки публичных заявлений. Сохраняйте прямые ссылки, даты и контекст; отделяйте подтверждённые факты от предположений.

Используйте только публичные материалы и законные источники. Инструмент не строит профили частных лиц, не определяет местоположение по косвенным признакам и не делает выводы о родственных связях.

1. Поиск YouTube

Поиск через серверную функцию. Ключ YouTube Data API хранится в переменных окружения Vercel, а не в браузере.

2. Поиск Mastodon

Ищет публичные статусы на выбранном сервере. Результаты зависят от политики и индексации сервера.

3. Журнал доказательств

Добавляйте найденные публичные материалы вручную, чтобы сохранить проверяемую цепочку источников.

Журнал сохраняется в локальном хранилище этого браузера; экспортируйте JSON для резервной копии или переноса на другое устройство. Перед публикацией перепроверьте ссылки, даты, оригинальный контекст и независимость источников.
